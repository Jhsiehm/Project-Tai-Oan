## Open items added in the Phase 1 build
- Sources taken from the Blueprint Sources tab into `data/sources.seed.json` were not re-opened in that session; `verified_via` says so. Re-open each and add page references before raising confidence.
- Japanese-era sugar figures: none are used. Only the Qiaotou 1902 date and the 5 April 1908 sugar railway date appear.
- Qiaotou mill: name the operating company from a source; confirm the colonial-era Chinese name.
- Chianan: academic source on labor and water fees (`todo-chianan`). Irrigated area differs by source (100,000 to 150,000 hectares), so no figure is shown.
- All map geometry is schematic (`todo-geometry`), including the assumed 1908 rail route through Taichung.
- Indigenous peoples areas are placeholders pending a sourced map and community review (`todo-peoples-map`).

## Map data
- Coastline: [Natural Earth](https://www.naturalearthdata.com/) 1:10m land, version 4.1.0, public domain. Redistributed as TopoJSON by [world-atlas](https://github.com/topojson/world-atlas) (ISC license). Generated by `scripts/build-outline.mjs` into `src/geo/taiwan-outline.json`.

## Caveats
- Many books were confirmed only via abstracts, reviews or catalog pages. Fetch page references before publish.
- Wikipedia is orientation only. Never cite it in the final piece.
- Several Chinese-language op-eds/blogs are flagged as commentary, not sources.
